Common questions

Which runtimes are local?

JavaScript and the built-in browser runtimes stay in the tab. Compiled languages can run through the local Sprig runner or a Piston-compatible server.

Does my code get uploaded?

Browser runs stay in your tab. Wandbox and TIO receive source code and input when you choose those providers, or when Auto chooses them, and run a program. Custom engines receive code sent to the endpoint you configure.

Can the list grow?

Hosted Sprig loads distinct language families from TIO and compiler versions from Wandbox and TIO. Open Settings and choose Sync languages to refresh them or load runtimes from your own engine.

Ask about your code, request a change, or get help with an error. Sprig AI runs on your computer, with no API key. It tries to test and fix supported code up to five times. If it can't test the code, it'll say so. If the tests keep failing, it'll mark the code broken. Always review the result.

Setting up Sprig AI
On 64-bit Windows, run powershell -ExecutionPolicy Bypass -File .\scripts\setup-local-ai.ps1 once to install the model (about 2.1 GB). To test code, start Docker Desktop and run powershell -ExecutionPolicy Bypass -File .\scripts\setup-ai-testing.ps1 (several GB). Then restart Sprig. You can follow along under Activity. A passing test isn't a guarantee; unsupported or unavailable tests are marked untested. The hosted site only has basic offline error hints.
