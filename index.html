Just the useful parts

      
A plain editor, real files, and quick runs. No account maze.

      

        
Quick starts
JavaScript, Python, Lua, and a few other languages run without an upload or setup.

        
Stop when needed
Runs in a worker and times out, so a loop should not freeze the whole page.

        
Use real files
Open a file or folder, edit it, and save straight back. Works in Chrome, Edge, and Opera.

        
More runtimes
Connect a local runner or Piston-compatible engine when you need extra compilers.

        
Type in the terminal
Stdin is the terminal itself. Press Enter to add a line, then run. A waiting program takes the next line as you type it.

        
Light or dark
Follow your system, or switch themes whenever you feel like it.

A few answers

      
Which runtimes are local?
JavaScript and the built-in browser runtimes stay in the tab. Compiled languages can run through the local Sprig runner or a Piston-compatible server.

      
Does my code get uploaded?
Browser runs stay here. Hosted engine languages use OnlineCompiler.io by default; its privacy policy says execution history, including code and input, is retained for up to 365 days.

      
Can the list grow?
Open Settings and choose Sync languages. Installed runtimes from a compatible engine will appear in the language menu.

Remote engine

  
Engine languages send your code to the configured execution service. A local Sprig install can use Piston on port 2000; a hosted site needs a publicly reachable Piston-compatible endpoint. Flix and Effekt require the local runner.
