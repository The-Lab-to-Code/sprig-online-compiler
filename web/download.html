02 / GOOD TO KNOW

The little details.

What's included?

The editor, local runner and browser assets. Language toolchains, the optional AI model and Docker for AI testing are separate installs.

Where does my code run?

Browser runs stay in the app. Online engines receive the code and input you send them. Local and separate-terminal programs run with your user permissions, not in a sandbox.

Windows security

Sprig's installer is not code-signed, so Windows may show a security warning. Only download it from the official release linked here.
